Four lines from bucket to answer.

Point PetaByteMind at your data, then ask in plain language. No cluster to size, no index to tune.

quickstart.ts 
import { PetaByteMind } from "@petabytemind/sdk";

const mind = new PetaByteMind({ apiKey: process.env.PBM_KEY });
const stream = await mind.ingest("s3://warehouse/events", { shards: 4096 });
const answer = await mind.ask("Which cohorts churn after day 30?", { stream });

console.log(answer.insight); // ranked cohorts, with evidence
